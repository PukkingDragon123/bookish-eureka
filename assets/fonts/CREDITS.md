# Fonts

Real webfonts for the non-pixel UI, fetched from the npm registry (the only
font source reachable under this workspace's network policy — Google Fonts and
the CDNs are blocked).

- **Inter** — UI and body text. SIL Open Font License 1.1. via `@fontsource/inter`
- **Nunito** — rounded display face for headings/numbers. OFL 1.1. via `@fontsource/nunito`

Weights kept: Inter 400/500/600/700, Nunito 400/600/700/800 (latin subset only).
